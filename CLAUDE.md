# Project rules
- Python 3.11+, src layout (`src/<package>`), pytest, ruff. Type hints on public functions.
- No fabricated results. Every table/figure in README is regenerated by `make results` from files under `runs/` or `data/`.
- Data and secrets are never committed: `data/`, `runs/raw/`, `.env` are in .gitignore. Load API keys from `.env` via python-dotenv.
- Each phase ends with: tests passing (`pytest -q`), `ruff check .` clean, a short CHANGELOG entry, and a commit message I write myself.
- Prefer small, readable modules over clever ones. I must be able to explain every file in an interview.
- When unsure about a physics or aviation fact, say so in a comment and in the README "Limitations" section instead of guessing.
